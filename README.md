ATM Simulator (HTML, CSS, Bootstrap, JavaScript) - Project Description
Overview:
This is a simple ATM Simulator built using HTML, CSS (Bootstrap), and JavaScript. It focuses on the core logic of ATM operations such as checking balance, withdrawing money, and depositing funds. The interface is clean and responsive, utilizing Bootstrap for styling and JavaScript for functional logic.

Features:
User Authentication (Optional) – A simple PIN-based login system.
Check Balance – Displays the current account balance.
Withdraw Money – Allows users to enter an amount and withdraw if sufficient balance is available.
Deposit Money – Lets users add money to their balance.
Transaction Logs (Optional) – Records past transactions.
Technology Stack:
HTML – Structure for the ATM interface.
CSS (Bootstrap) – Styling and layout for a responsive design.
JavaScript – Implements logic for balance updates, withdrawals, deposits, and error handling.
Functionality Breakdown:
Balance Handling: Stored as a variable and updated dynamically.
Input Validation: Ensures valid amounts (e.g., no negative values, sufficient balance for withdrawals).
User Interaction: Buttons trigger JavaScript functions to perform ATM operations.
Error Handling: Alerts the user if they enter invalid amounts or exceed balance.
